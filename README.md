
# ProyectJeep

Proyecto impulsado por la cátedra de Traductores e Interprétes en el programa de Ingeniería Informática de la U.N.E.R.G




## Features

- Agente de IA adaptado a marcas y a los modelos más populares del mercado
- Api de código abierto proporcionada por API Ninjas
- Funcionamiento en modo ventana para la accesibilidad del usuario promedio
- Resultados instantáneos




## FAQ

#### ¿Se seguirá el desarrollo del agente?

Si recibe una buena aceptación y feedback al respecto, por supuesto que sí

#### ¿Los resultados del agente son confiables?

Al tratarse de una versión preliminar, no, pero lanza resultados lógicos, acorde a la realidad del vehículo
